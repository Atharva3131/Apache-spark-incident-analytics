EXAMPLE USAGE
================================================================================

In Python:

  from src.generator.log_generator import LogGenerator
  from src.ingestion.log_ingestion import ingest_records
  from src.processing.spark_processor import get_spark_session, SparkProcessor
  from src.detection.anomaly_detector import AnomalyDetector
  from src.correlation.incident_correlator import IncidentCorrelator
  from src.investigation.rca_engine import generate_deterministic_rca

  # Generate logs
  gen = LogGenerator(seed=42)
  records = gen.generate(scenario="db_exhaustion", n_normal=2000, n_incident=500)

  # Setup Spark
  spark = get_spark_session(master="local[*]")
  df = ingest_records(spark, records)

  # Process
  processor = SparkProcessor(spark, window_minutes=5)
  results = processor.run_full_pipeline(df)

  # Detect anomalies
  detector = AnomalyDetector()
  anomalies = detector.detect(results["service_metrics"])

  # Correlate
  correlator = IncidentCorrelator()
  correlation = correlator.correlate(anomalies, results["service_metrics"])

  # Generate RCA
  rca = generate_deterministic_rca(correlation, results["service_metrics"])

  # Results ready for storage or display
  print(rca.incident_title)
  print(rca.probable_root_cause)
  print(rca.recommended_actions)

CONFIGURATION OPTIONS
================================================================================

Spark:
  SPARK_MASTER=local[*]              # local[N], spark://..., k8s://...
  SPARK_DRIVER_MEMORY=2g             # Increase for large datasets

Anomaly Detection:
  ERROR_RATE_THRESHOLD=0.1           # 10% error rate
  LATENCY_SPIKE_THRESHOLD_MS=2000    # 2 second average latency
  MIN_ERROR_COUNT=5                  # Minimum errors to flag
  WINDOW_MINUTES=5                   # Time window for aggregation

MongoDB:
  MONGODB_ENABLED=true               # Enable/disable persistence
  MONGODB_URI=mongodb://localhost:27017
  MONGODB_DATABASE=incident_intelligence

Sarvam AI:
  SARVAM_API_KEY=your_key            # Get from sarvam.ai
  SARVAM_MODEL=sarvam-m              # Model name
  SARVAM_API_BASE_URL=https://api.sarvam.ai/v1
